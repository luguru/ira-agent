Lanza tu auditoria en minutos

Define alcance, criterios y dispositivos en una sola pantalla. El motor ejecuta Playwright + axe-core y genera informe HTML, JSON y Markdown.

  • Configuracion guiada sin tocar JSON manualmente.
  • Control total de maxPages, maxDepth, tags y viewports.
  • Salida lista para seguimiento tecnico y operativo.

Nueva auditoria

Solo la URL es obligatoria. El resto usa valores por defecto si lo dejas vacio.

Que significa cada opcion
  • URL a analizar: direccion de la web que quieres revisar.
  • Titulo de la auditoria: nombre interno para identificar esta revision.
  • maxPages: numero maximo de paginas que se revisaran.
  • maxDepth: cuanto puede profundizar el rastreo en enlaces internos.
  • Analizar sitio completo: intenta recorrer todo el sitio. Puede tardar mas.
  • axeTags: conjunto de comprobaciones automaticas de accesibilidad.
  • viewports: tamanos de pantalla donde se ejecuta la revision (movil/escritorio).
