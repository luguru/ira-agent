# Código de conducta

Este proyecto adopta el Contributor Covenant, versión 2.1.

Todas las personas participantes deben mantener un entorno respetuoso, inclusivo y libre de acoso. No se toleran ataques personales, discriminación, intimidación, publicación de información privada ni conductas deliberadamente disruptivas.

Los problemas de conducta deben comunicarse de forma privada al mantenedor del repositorio. Las incidencias se evaluarán de manera confidencial y podrán implicar advertencias, eliminación de contenido o exclusión temporal o permanente de los espacios del proyecto.

Texto de referencia del Contributor Covenant 2.1:
https://www.contributor-covenant.org/version/2/1/code_of_conduct/
